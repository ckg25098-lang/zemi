# テーマ1　テーマ「日田市紹介サイト」日田市の魅力を紹介する情報サイト

## 概要
概要

日田市の観光スポットやグルメ、イベント、基本情報などを写真とともに分かりやすく紹介し、日田市の魅力を発信するWebサイトを制作する。

### ページ１

トップページ：日田市の魅力を簡単に紹介

### ページ２

日田市の基本情報：日田市の位置や歴史、人口、特産品などの基本情報を紹介する。
基本情報（位置・歴史・人口・特産品など）
文章量：約500～700文字
写真：3～5枚

### ページ３

観光スポット：日田市の代表的な観光スポットや見どころを紹介する。
紹介する観光スポット：8～10か所
写真：各スポット1～2枚（合計10～15枚程度）
文章量：各スポット約100～150文字

### ページ４

グルメ：日田市の名物料理やおすすめの飲食店を紹介する。
紹介する飲食店・名物料理：5～8店舗（品）
写真：各店舗・料理1枚（合計5～8枚程度）
文章量：各店舗・料理約80～120文字

### ページ５

イベント：日田市で開催される季節ごとのイベントを紹介する。
紹介するイベント：5～6件
写真：各イベント1枚（合計5～6枚程度）
文章量：各イベント約100文字

### ページ６

アクセス：日田市へのアクセス方法や周辺地図を掲載する。
日田市へのアクセス方法
地図：1～2点
文章量：約300～500文字
交通手段（JR・高速道路・バスなど）を掲載


# テーマ2　　テーマ「日田市３Ⅾ観光マップの制作」3Dマップを使って観光地の位置関係を分かりやすく示し、観光を支援するWebコンテンツ

### ページ１

トップページ：サイトの概要
3D観光マップの使い方
各ページへのメニュー

### ページ２

3D観光マップ：日田市を簡略化した3Dマップ
制作範囲
日田市を簡略化した3Dマップを制作
テーマ１で紹介した観光スポットを3Dマップ上に配置
地形・建物を簡易的な3Dモデルで表現
山・川・道路を簡易的に表現

機能
マウスによる回転
拡大・縮小
観光スポットの表示
観光スポットの選択（クリック）
